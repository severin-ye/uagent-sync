## 有界词法与语句边界

新增独立profile-php-ruby.ts，不将PHP映射JS或Ruby映射Python。按语言识别源片段或闭合围栏；独立token处理普通引号字符串、PHP行/块注释、Ruby行注释及括号内换行。整个代码区必须恰好匹配单条指定构造语句与单个命名/关键字参数；PHP要求分号，Ruby要求闭括号后仅空白或注释。精确单/双引号占位符必须是完整值，只掩码其14个UTF-16码元，原始偏移、LF/CRLF和其他内容不变。

heredoc/nowdoc、Ruby百分号字符串/文档块、插值、显式续行、PHP标签转换等不尝试跨越或解码：整区不做任何掩码。普通字符串中的示例也不解释为源码。附加字段、拼接/回退、邻接值、其他语句、未闭合/不匹配结构均失去整区允许；含候选键名的未识别区增加保守拒绝，避免允许前缀暴露已有扫描缺口。注释保持原文，并对敏感赋值形状保守拒绝。

**当前缺口明确保留**：同一区域包含import/require、默认客户端示例加显式示例、多条合法语句或更广语言语法，仍会阻断。需要额外的专用语句解析与拒绝测试才能扩大；不能声称历史README完整围栏或真实文件已通过。逐候选与限制见[candidate-scope.json](candidate-scope.json)。
