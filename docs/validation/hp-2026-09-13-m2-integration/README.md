4. 残留保护只认可M13已消除的表达式及有限None惯用形式；其他未解释值语法撤销本文件全部M2跨度。部分原型能解析的注解参数（例如api_key: str = None）在组合层仍弃权，这是明确保守差异，不代表真实四处通过，也不为覆盖率临时放宽。同行/邻接凭据、None元组与注释中的第二个赋值继续阻断。
