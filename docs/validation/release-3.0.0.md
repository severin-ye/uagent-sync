# 3.0.0 发布与验收记录

## 基线与判级

2026-11-01 从官方 npm registry 固定下载的 `uagent-sync@2.1.0` 和 `uagent-sync-dsh@2.1.0` 是本批实际发布基线。源码 package.json 的 2.5.1 未在 registry 发布（精确查询 E404），不能作为已发布基线。历史 2.2.x–2.5.1 日志保留为其原有源码记录，不补造逐版本发布。

2.1.0 CLI tarball 的 Node 安装声明为 `>=18`；当前固定生产依赖要求 `^22.22.2 || ^24.15.0 || >=26.0.0`。旧安装支持范围被移除，独立满足现行发布契约的 X 条件，因此本批统一为 **3.0.0**。device、受保护插件内容恢复、统一私有配置与项目备份、迁移决定写入、自更新隔离等累积变化一并交付，不按旧源码号机械发 2.5.2。旧入口及兼容状态读取保留。

根包、锁文件、DSH bundle 与其精确 CLI 依赖、Codex 清单和市场清单同步为 3.0.0。官方 GitHub Release workflow 同时生成两个 tarball 及 SHA256SUMS。

## 证据边界

本记录随候选准备维护。正式 npm 发布、registry 重新下载完整性、独立 DSH 分发物生命周期和商城准入分别核验；候选包通过不等于正式发布完成。

- 软件检查：Node24.19.0 下项目要求的一轮全量 `npm test`（包含构建）1070/1070 通过，零失败/取消/跳过；`npm run typecheck` 通过。当前仅版本、发布配置和文档变化，浏览器端实现未变，复用本批前序 G05/G06 固定源码的浏览器 E2E 证据，不重复运行。
- 固定产物：构建真实 CLI 和 DSH tarball，逐包核对版本、文件清单、运行数据/已知字面凭据排除与 SHA-256；这是有界内容检查，不是独立安全或供应链审计。
- CLI 消费者：使用独立 npm global prefix/cache/userconfig/globalconfig、禁用 workspace 发现并逐次核对 private 消费者身份及实际 prefix；观察到 Node24.19.0 与 bundled npm11.17.0。精确 tarball 的 3.0.0 安装、help/version、device/backup help、回退 2.1.0 及其 help、重新安装 3.0.0、卸载与包/shim 无残留均通过。不引用本地源码 checkout；这仍不等于 registry 重新下载验收。
- DSH：0.2.1-rc.5 的本次固定包 registry 生命周期待正式 CLI 依赖发布后执行，旧 local-link 结果不替代。0.1.0-rc.6 元数据可取得，但本次隔离宿主安装未完成，保持 unknown，不再尝试其他路径。
- 商城：`dsh.compatibility.dshReleases` 保持 unknown。供应链/权限专项审核和商城受保护安装资格由对应商城流程决定，作者本地测试不自授准入。

未运行真实私人备份、设备注册/同步、真实用户配置写入或模型调用。一次性资源和原始日志留在本次私有任务证据目录，由协调者在发布验收结束后依资源登记处理；不将私人路径、配置、token 或快照上传仓库。
