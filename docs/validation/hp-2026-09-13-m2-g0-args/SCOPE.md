# 修复结果、保守差异与未验证项

## 有限状态合同

1. docstring标题缩进必须等于独占结束引号行的空格缩进；标题前只允许空白。Args必须唯一且先出现，之后可选Returns再Raises，或直接Raises；重复/倒序/未知标题弃权。
2. Args第一条必须是当前函数的真实形参名与单行非空说明；它确定直接条目的共同缩进（深于标题，不硬编码为4格）。全部后续条目须同层且关联本函数，名字不能重复。默认表达式名称不算形参。空行可位于条目前后和节间，不改变所属状态。
3. 同级未知段落、额外字段、更深Example/参数、说明续行、空行后续写不能证明直接归属，整文件弃权。处理完整docstring后才并入pending；后续函数报未知归属时返回empty清空整个结果。
4. Returns/Raises仅支持零或一条直接单行说明，与参数条目同缩进。可为无冒号单行说明，或简单TypeName: 非空说明；不允许把当前函数形参名写成该节字段。段内嵌套、两行/两段说明、复杂类型语法未支持，保守弃权。节内文字从不获得M2跨度。
5. 原始LF/CRLF、UTF16非BMP前缀位置、7字符字段跨度保留。提供多参数、Returns、Raises、两节、空行和不同直接缩进六个允许配对；新增十二拒绝配对均测单独文件和正常候选在前的文件。

## 保守差异

相比旧原型，标题前有摘要文字、结束引号同一行有正文、缩进不符合上述版式、一般多行参数说明或返回说明也会弃权，即便可能是合法文档。不能用这些格式限制宣称覆盖真实四处；本轮没有读取真实模板或文件来扩大范围。

之前已经接受的全文件FormatString弃权、顶层非目标普通函数参数校验、通用unavailable原因保留。没有新增生产允许；原型的有限允许与完整Python/docstring语义不是一回事。

## 未验证

没有生产可信宿主注入、实际每操作一次加载接线、三入口副作用验证、完整Python语义/资源性能证明、真实CLI/plugin打包兼容或真实凭据拒绝验收。人工模板与描述始终为Synthetic内容。未知来源172项和链接来源问题不在本轮，未重查。
