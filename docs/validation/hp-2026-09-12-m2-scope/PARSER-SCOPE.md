# 生产语法定位合同（推荐，未实现）

## A. 依赖与运行边界

建议@lezer/python精确1.1.18作为纯Node生产依赖候选，ESM入口适配当前项目。该包包含生成后的JS语法；不运行Python、不运行外部被检代码、不需要本地编译原生绑定。发布前必须在Node18和当前Node实际测试import、strict parse、异常、输入偏移、打包后的CLI/plugin调用。npm包文件/锁定完整性/许可证及common、lr、highlight实际resolved版本需记录；本轮只有源文件与包声明核对，没有npm安装或兼容结论。

上游lr源码已确认configure({strict:true})和语法错误抛出SyntaxError；不使用默认恢复，不带incremental fragments、裁剪ranges、parse wrapper或语言嵌入扩展。节点名称以固定grammar为依据，未来实际节点快照必须验证后才能接入生产。它是语法树而非CPython语义验证器；错误节点为零不证明所有Python语义有效，候选仍受下表额外结构限制。

## B. 两阶段状态及错误传播

S0取得调用者提供的完整UTF-8解码文本和可信模板快照；非法解码/BOM/不支持换行（仅LF或CRLF）/无效模板→M2返回空集合及不含正文的原因码。

S1用strict parser解析完整输入到EOF，核对根为Script、覆盖[0,content.length]，遍历全部节点（包括匿名与零宽节点）检查type.isError、越界、缺失终止符。任何异常、错误节点、资源上限或无法确认的解析状态→整文件M2弃权。不得在候选后遇错仍返回早先结果。

S2建立FunctionDefinition→其直接ParamList和Body→其第一条实际Statement的关联，只使用树父子/同级关系，不跨相邻函数搜Args/api_key。候选先存pending数组；完整文件遍历结束及所有不变量通过后才提交。识别层不修改原文。

S3校验普通STRING原文与Args结构、精确模板正文，记录原7字符区间。所有区间合法、互不重叠且文件最终状态有效时一次返回。

异常传播合同：M2对语法/模板问题返回 {spans:[],reason:<enum>}，保留原扫描，不把空掩码等价为文件安全，也不清除既有M0/M13结果。调用方仍扫描原始前缀/Bearer和其他规则。开发缺陷/不可预期内部异常也不得返回pending掩码；诊断不输出被检正文。未来测试要分别断言M2无掩码、危险输入实际被拒绝及三入口副作用，而不是混用这三种结论。

## C. 支持/弃权表

| 部位 | 首批支持 | 不支持/失效行为 |
|---|---|---|
| 文件 | 固定版本grammar可严格完整解析的.py；全文件原文保留 | 语法/词法错误在前或后均整文件M2弃权；不逐行恢复 |
| 函数 | Script直接子节点的同步FunctionDefinition，独立块式Body | async、decorated、嵌套、类方法、单行Body不是候选；不跨这些边界关联 |
| 签名 | 完整ParamList括号及Body冒号；普通位置参数、裸*后的keyword-only；唯一api_key直接属于该列表 | 重复参数、非法星号次序、多个裸*、无完整参数/冒号等候选签名不确定时整文件M2弃权；/、*args、**kwargs不进入首批候选 |
| 注解 | TypeDef子树完整，括号/下标/字符串内冒号由grammar定位；只读取实际参数名 | 不从注解内部VariableName猜形参；未知节点关系弃权；不求值 |
| 默认值 | 完整合法表达式子树可含嵌套括号、Name、常量或调用，均仅跳读其span | 默认值内容保持原样扫描，不执行/解码，不认为变量/调用值无秘密；边界不能确认则整文件M2弃权 |
| 函数首语句 | 忽略注释与空行后的第一个实际Statement必须是ExpressionStatement，仅一个String表达式 | AssignStatement、CallExpression、StatementGroup分号组合、括号包装、拼接/格式化/多个相邻字符串都非候选 |
| 文档字符串 | 原token从普通三双引号开始并完整结束，无前缀、转义和插值；token与表达式范围严格对应 | f/r/u/b等前缀、单引号/三单引号、转义或嵌入伪字符串不支持；字符串完整性不确定整文件弃权 |
| Args | 文档字符串内唯一独立Args:标题，无尾空格；候选条目缩进严格深于该节标题，api_key只出现一次 | 伪标题、重复Args/字段、介入其他节、归属不明确→本文件M2弃权；不扫描邻函数拼接归属 |
| 条目 | ASCII空格缩进、精确api_key冒号及一个ASCII空格、模板逐字正文直到行尾 | tab缩进、额外空格/大小写/Unicode变体/额外值不得匹配；继续扫描原文 |
| 终止 | 越过空行找到下一非空行，只能同级下一参数或退回节级/结束引号 | 更深缩进续写（即使隔空行）或未知段落归属→候选不掩码；候选内部边界不确定时整文件弃权 |

首批词法支持表不声称验证任意函数语义。若实际节点形状、参数合法性或终止关系无法在上述限制内可靠判断，就报告弃权；不能为了清除四项扩大语法。

## D. 原始跨度

输入以原JS字符串不归一化地传给parser；common的StringInput采用JS length/slice，可用from/to定位UTF-16区间。保留整文件换行索引，最终只对api_key区间[begin,begin+7)写空格。tokenize字符列、AST UTF-8字节列仅用于未来测试参照，不能直接写入JS索引。转换函数必须针对同一行非BMP、前面多字节字符及更早行分别验算；原始行号来自未改文本，不来自重组docstring或缩进规整结果。
