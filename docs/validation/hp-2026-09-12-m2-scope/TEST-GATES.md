# 合并荣耀补充后的进入与验收门槛

本文件取代对T01–T12的含糊解释，不宣称已写或运行测试。

| 门槛 | 具体必测 | 失败分类/结果 |
|---|---|---|
| G0 依赖原型 | 单独未来授权的隔离原型，固定@lezer/python 1.1.18及lock版本，在Node18/当前Node、ESM/发布包下验证实际树形、strict抛错、isError、UTF16位置及资源界限；只用人工数据 | 兼容性/环境失败不是安全红测；不通过不接入 |
| T01 四布局 | 四人工安全布局，D2两位置，位置与keyword-only参数；说明值只用人工模板 | 安全允许断言在旧版真实失败，不能用模块不存在充数 |
| T02 精确正文 | 同长度替换、尾部空格、大小写、Unicode相似字/NFC-NFD差异、截断/前缀追加、冒号多空格 | 模板不精确匹配不获M2掩码，绝不按长度允许 |
| T03 危险配对 | 尾部单独与安全说明+尾部，文档内/外/相邻函数；全部敏感键别名大小写、引号/注释/括号/模板值 | 独立记录每一组合实际拒绝；发现旧缺口须单列，不能以空M2掩码冒充拒绝 |
| T04 延伸 | 闭引号后拼接/回退/插值/调用及空行后深缩进续写 | 语法错误整文件撤销；合法非候选不掩码；危险组合另断言拒绝 |
| T05 后置错误 | 候选之前和之后的未闭合字符串、括号、非法token；多候选前成功后失败 | pending集合整体清空，不保留先前掩码；既有M13掩码单独核对 |
| T06 错归属 | 伪Args、另一节介入、重复api_key/Args、邻函数才有同名参数、嵌套函数及赋值/help字符串 | 父子关系和节边界不成立不得匹配 |
| T07 完整签名 | 注解、嵌套默认表达式、字符串内冒号、裸*位置、重复参数、/或*args/**kwargs等不支持形式 | 按支持表通过/弃权，不求值；默认表达式危险内容独立扫描 |
| T08 位置 | 同行前缀与更早行非BMP、UTF8字节列/token字符列/JS UTF16偏移分别比对，LF/CRLF，多个docstring | 全串比较仅7单元变化、后续行号保持 |
| T09 原文保护 | 文档正文/注释中的前缀/Bearer和额外敏感字段 | 原始扫描不被掩码影响 |
| T10 三入口 | 两文件布局，允许/拒绝逐入口分开；人工manifest重算摘要 | 无快照目录、目标与baseline字节不变、mock Git调用增量0；禁止真实网络发布 |
| T11 历史回归 | M0/M13/SEQ等全部原测试与失败材料保留 | 旧已拒绝仅记回归，新允许或实际漏检才记红态 |
| T12 真实复扫 | 未来固定新源码后仅只读13文件，旧摘要/前后摘要与漂移 | 四M2消失和其他三项保留分开计数，不创建真实快照 |
| G1 模板故障 | 无模板/错版本/重复ID/无权限/受检内容伪造路径/快照覆盖/provider竞态 | 无M2掩码、无正文日志；三入口使用一致冻结模板 |

阶段顺序：荣耀范围意见→用户另行明确依赖原型与模板交付→原型通过、规则准备好→再明确启动红测/实现→完整回归与只读复扫。若范围仍有分歧，只返回具体差异，不反复重做四处取证。HP-03/HP-04及迁移全程保持未完成，直到各自原验收条件另有证据。
