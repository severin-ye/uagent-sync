# 实测合同和保留缺口

1. Lezer树证据覆盖FunctionDefinition、ParamList直接VariableName/AssignOp、TypeParamList、Body和ExpressionStatement(String,逗号)；不假定有Param子节点。默认Name不算形参；直接子节点间非空白原文使参数弃权，防止匿名/遗漏。注解及嵌套调用默认值有人工测试，但不是CPython全面语义验证。
2. 全文件strict解析后遍历全部String核对原始闭合；任意FormatString直接整文件弃权。短字符串换行不接受，三引号必须真实结束；不依据零宽节点一概拒绝，合法EOF已测。rawClosed不是通用Python词法器：未知前缀/格式须保持不支持，不可直接扩允许。
3. 顶层同步普通函数为候选，TypeParamList跳过；首个块式语句必须完整等于单一未加前缀、无转义的三双引号String。纯字符串API不声称识别原字节解码损失；严格UTF8字节层另测，合法U+FFFD允许；BOM/loneCR拒绝，LF/CRLF原位置不归一化。
4. Args唯一标题和api_key条目名在同一个docstring；下一同级条目必须属于当前函数参数，Returns/Raises退节有受限规则，空行后的延伸不自动截断。精确描述以人工D1–D3为准，长度/ID/摘要不作允许规则。返回的只有原文7字符跨度；不含字符串解码或执行。
5. 整文件原始闭合检查在任何候选返回前完成，晚出现畸形候选签名会清空早先pending。当前原型额外检查所有顶层普通函数的参数不变量，较RY-14建议的“只检查候选签名”更保守；无api_key函数的非法默认顺序也使整文件弃权。此差异须荣耀确认，不能声称完全等同生产合同。
6. provider只有可信宿主显式创建，普通对象不能伪装模板。闭合schema/版本/D1–D3完整互异/精确field、重复键含转义同名、UTF8、16KiB总量和256 UTF16每项均有拒绝门槛。数据JSON允许解码，受检正文不解码/trim/归一化。私有WeakSet只是原型进程内来源标记，不是任意可执行调用者的安全沙箱。
7. 每次begin调用恰加载一次；操作内复用同一复制/深冻结对象，多操作不共享可变currentTemplate。并发、读取失败、复制故障、源字节修改均有人工测试。没有生产枚举器；“每实际采集/恢复/publish操作只加载一次”尚未接线验证。
8. 依赖安装后和打包消费者实际版本均已检查，lock含完整性值。模板自报版本必须符合常量；生产依赖供应链身份验证/发布打包约束尚未设计完成。此原型没有新增Python运行依赖。
